# Implementation Plan: Exam Page

**Branch**: `004-exam-page` | **Date**: 2026-04-16 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `/specs/004-exam-page/spec.md`

## Summary

Implement the active Exam page for Lumina AI — the core exam-taking experience for students. After entering a valid exam code (spec 003), the Electron renderer navigates to this page, which retrieves the full `ExamSession` (attemptId, title, duration, questions) from a module-scope variable in main.js via `bridge:get-exam-session`. The page renders the question and choices one at a time, maintains an in-memory `answerMap` keyed by question ID, and provides previous/next navigation, a question navigator pill row, and a "Jump to" input. A drift-corrected countdown timer counts down from `examSession.duration`; at 00:00:00 answers are auto-submitted. Manual submission goes through a confirmation modal. In both paths, the submit payload (`{ answers: [{ questionId, choiceId }] }`) is sent to main.js via `bridge:submit-exam`, which reads the access token, forwards to the Python bridge at `POST /submit-exam`, and the bridge calls `POST /api/QuizAttempts/submit/{attemptId}` on the LMS. A `SubmitResult` is stored in main.js module scope for retrieval by spec 005 via `bridge:get-submit-result`. A live `<video>` feed from `getUserMedia` is shown in the proctoring panel; AI status rows are static placeholder labels. All tracks are released on navigation away. No logout control exists on this page.

## Technical Context

**Language/Version**: Node.js 20 LTS (Electron 33+) / Python 3.11+  
**Primary Dependencies**: Electron 33, keytar 7.x, Flask 3.x, flask-cors 4.x, requests 2.32+, @fontsource/manrope, @fontsource/inter  
**Storage**: OS keychain via keytar (existing session — read only in this spec); module-scope `examSession` (read only, written by spec 003); module-scope `submitResult` (written once on submit success, read by spec 005 via IPC)  
**Testing**: Manual + mock JSON fixtures in `specs/004-exam-page/mocks/`  
**Target Platform**: Windows 10+ desktop application (Electron)  
**Project Type**: desktop-app  
**Performance Goals**: Exam page loads and first question visible within 2 seconds of navigation; IPC retrieval of ExamSession < 500 ms; submit round-trip < 5 seconds on local network  
**Constraints**: All HTTP to LMS must go through Python bridge; renderer uses IPC only; no fetch() from renderer; JWT passed from main.js to bridge in request body only; no logout from exam page; no persistent state beyond module-scope in main.js  
**Scale/Scope**: Single-user desktop app; one active exam session at a time; up to ~100 questions per exam
