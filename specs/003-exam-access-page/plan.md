# Implementation Plan: Exam Access Page

**Branch**: `003-exam-access-page` | **Date**: 2026-04-15 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `/specs/003-exam-access-page/spec.md`

## Summary

Implement the Exam Access page for Lumina AI — the authenticated gate between login and the active exam. A student enters an instructor-supplied exam code and clicks "Join Exam". The Electron renderer calls an IPC handler in main.js, which reads the student's JWT from the session store, forwards the request to the Python bridge at `POST /exam-access`, and the bridge issues a `GET /api/QuizAttempts/attempt/{quizCode}` to the LMS with the Authorization header. On success, the full ExamSession (attemptId, title, duration, questions) is stored in main.js module scope and the renderer navigates to the Exam page. All five error paths (empty input, code not found, already attempted, expired token, network failure/timeout) are handled with distinct sanitised messages and proper recovery (input re-enabled, value preserved, error clears on keystroke). The page matches `Designs/Exam_Code_Page/screen.png` using only Ethereal Authority design tokens.

## Technical Context

**Language/Version**: Node.js 20 LTS (Electron 33+) / Python 3.11+  
**Primary Dependencies**: Electron 33, keytar 7.x, Flask 3.x, flask-cors 4.x, requests 2.32+, @fontsource/manrope, @fontsource/inter  
**Storage**: OS keychain via keytar (existing session — read only in this spec); module-scope `examSession` variable (in-memory, not persisted)  
**Testing**: Manual + mock JSON fixtures in `specs/003-exam-access-page/mocks/`  
**Target Platform**: Windows 10+ desktop application (Electron)  
**Project Type**: desktop-app  
**Performance Goals**: Exam start round-trip < 5 seconds on local network; 15-second hard timeout  
**Constraints**: All HTTP to LMS must go through Python bridge; renderer uses IPC only; no fetch() from renderer; no credential storage in renderer; JWT passed from main.js to bridge in request body only  
**Scale/Scope**: Single-user desktop app; one active exam session at a time
